## Configuration and interpretation

Use `--conditioning-attention directional|bidirectional` and
`--clean-motion-timestep omit|zero`. Defaults preserve the original tensor
behavior. Existing `PHASE3_JOINT_TASK_WEIGHTS` accepts a zero joint weight:
`{"video2motion":0.5,"motimg2video":0.5,"joint":0.0}`. Zero-weight tasks are
removed from the effective task set. Both new launchers select `zero`.

Bidirectional mode allows generator and motion query tokens to read one another
across the existing time-aligned intervals, regardless of clean/noisy role.
Shape exchanges information globally with generator tokens. Same-stream attention
and native specialist attention retain their existing behavior. The flag does
not replace temporal locality with global frame-to-frame cross-attention.
The FP32 cached training path implements the same policy and caches each mode
separately. Five CPU checks cover meaningful reverse-direction influence,
temporal exclusion, legacy output parity, cached forward/backward parity and
checkpoint policy restoration/conflicts.

The original omission concerns **clean M2V motion**, not noisy V2M targets.
The user explicitly confirmed adding E_M(0) to the clean motion in both arms.
The implementation changes only the embedding mask; clean/target roles used by
the bridge remain separate. Clean M2V sigma is checked to be zero. Target V2M
continues using its actual normalized sigma. No Phase 2 weights are modified.
